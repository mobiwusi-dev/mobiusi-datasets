# Configuration Item Relationship Integrity Evaluation Benchmark

The data is provided as JSON records of configuration items and their dependency, connection, and composition relationships, covering common anomalies such as invalid references, conflicting relationship directions, and violated relationship constraints. It evaluates consistency and integrity checks across CMDB relationship graphs and includes expected validation outcomes with issue descriptions, supporting automated evaluation, rule validation, and configuration data quality audits.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| source_data | object | The original JSON record containing configuration items and their relationships. |
| integrity_check | object | The expected validation outcome, indicating whether the graph is consistent and describing any integrity issues. |
