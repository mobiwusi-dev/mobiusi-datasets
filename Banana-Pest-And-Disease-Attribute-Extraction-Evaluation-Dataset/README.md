# Banana Pest and Disease Attribute Extraction Evaluation Dataset

This evaluation dataset contains web text from banana pest and disease descriptions, production guidance, and control materials, organized around banana plant health issues. It pairs source passages with structured attributes such as health issue name, affected plant parts, symptoms, and occurrence status. The dataset supports benchmarking entity recognition, status understanding, and structured information extraction for banana production, as well as model comparison and agricultural text research.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| symptoms | array | Symptoms or damage caused by the pest or disease as described in the source text. |
| source_text | string | Web text from banana pest and disease descriptions, production guidance, or control materials. |
| affected_parts | array | Parts of the banana plant that are infected, damaged, or show symptoms related to the pest or disease. |
| health_issue_name | string | The name of the banana disease or pest mentioned in the source text. |
| occurrence_status | string | The reported occurrence, progression, or damage status of the pest or disease, such as its occurrence period, severity, or whether it is currently present. |
