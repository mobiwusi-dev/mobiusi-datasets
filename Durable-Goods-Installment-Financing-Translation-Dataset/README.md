# Durable Goods Installment Financing Translation Dataset

This dataset covers installment financing offers, payment plan explanations, and checkout financing options for durable goods purchases, including appliances, electronics, and furniture. Each bilingual parallel-text example pairs a translation instruction with source text, source and target languages, and a reference translation. The content supports domain-specific translation tuning, terminology consistency improvement, and evaluation of consumer finance copy translation.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| source_text | string | Original text about a durable goods purchase, installment plan, payment schedule, or checkout financing option. |
| source_language | string | Language of the original source text. |
| target_language | string | Language requested for the translation. |
| target_translation | string | Reference translation that preserves the meaning and terminology of the financing offer or payment plan. |
| translation_instruction | string | Instructions specifying how to translate the financing-related source text. |
