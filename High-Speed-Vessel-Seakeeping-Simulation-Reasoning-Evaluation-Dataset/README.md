# High-Speed Vessel Seakeeping Simulation Reasoning Evaluation Dataset

This dataset consists of synthetic text-based simulation scenarios covering wave conditions, vessel speed and heading, hull responses, and related simulation settings. Its analysis tasks address motion responses, load variations, and comparisons between operating conditions, with sample fields for reasoning, modeling assumptions and limitations, and final conclusions. It supports evaluation of scientific reasoning about high-speed vessel seakeeping simulations, as well as ship design research and simulation analysis.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| final_conclusion | string | A summary of the main analytical findings and judgments about the effects of operating conditions. |
| analysis_question | string | A task asking for analysis of motion responses, load variations, or comparisons between simulation conditions. |
| simulation_scenario | string | Text describing wave conditions, vessel speed and heading, hull responses, and relevant simulation settings. |
| scientific_reasoning | string | A logical derivation from simulation conditions to judgments about motion responses and loads, distinguishing known information from inferences. |
| load_variation_analysis | string | Analysis of how changes in waves and operating conditions affect hull loads and their trends. |
| motion_response_analysis | string | Analysis of trends in vessel motion responses and their possible causes based on the simulation scenario. |
| operating_condition_comparison | string | Comparison of motion responses and loads across simulation conditions, with possible influencing factors explained. |
| modeling_assumptions_and_limitations | string | Identification of the seakeeping modeling assumptions used in the analysis and how they may limit interpretation of the results. |
