# Territorial Spatial Use Conflict Diagnosis and Coordination Report Dataset

This dataset focuses on spatial use arrangements and control requirements in territorial spatial planning. It pairs inputs such as planned uses, resource conditions, and planning materials with outputs covering conflict identification, causal analysis, coordination recommendations, and integrated reports. The examples help models synthesize competing spatial needs, professional rules, and resource constraints to produce structured, long-form planning reports for review, coordination, and decision support.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| causal_analysis | string | A derived explanation of the regulatory, spatial, resource, or planning factors behind each identified conflict. |
| integrated_report | string | A complete long-form report integrating the diagnosis, reasoning, and planning coordination recommendations. |
| planning_materials | string | Relevant planning documents, extracted passages, or source notes used to assess spatial uses and applicable requirements. |
| resource_conditions | string | Source information about relevant land, water, ecological, infrastructure, and other resource conditions or constraints. |
| control_requirements | string | Source requirements and rules governing land use, zoning, protection, development, and spatial controls. |
| conflict_identification | string | A derived account of conflicting spatial uses, affected locations, competing objectives, and applicable requirements. |
| spatial_use_arrangements | string | Source information describing planned or existing spatial uses, their locations and boundaries, and their intended functions. |
| coordination_recommendations | string | Derived recommendations outlining feasible coordination paths, proposed adjustments, responsible parties, and implementation considerations. |
