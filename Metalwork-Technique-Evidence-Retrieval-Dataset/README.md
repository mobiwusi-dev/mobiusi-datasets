# Metalwork Technique Evidence Retrieval Dataset

This dataset brings together web text describing the characteristics, steps, and historical uses of metalworking techniques such as casting, forging, chasing, and gilding, paired with evidence passages that support answers to specific technique questions. It focuses on knowledge of metalwork heritage and includes source webpage text, technique questions, evidence passages, and technique names. It is suitable for training and evaluating evidence retrieval, knowledge question answering, and natural language processing systems in the metalwork domain.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| technique_name | string | The name of the metalworking technique identified from the question and evidence passage. |
| evidence_passage | string | A passage selected from the source webpage text that supports an answer to the technique question. |
| technique_question | string | A specific question about a metalworking technique, based on the source webpage content. |
| source_webpage_text | string | Original webpage text describing the characteristics, steps, or historical uses of metalworking techniques such as casting, forging, chasing, and gilding. |
