# Out-of-Home Advertising Creative Compliance Constraint Extraction Dataset

This dataset uses compliance instructions for out-of-home advertising creatives as input, covering requirements such as brand guidelines, mandatory disclosures, prohibited wording, and placement restrictions. Each record pairs the original instruction text with structured constraints, supporting models that extract rules from natural-language requirements and identify applicable subjects and restriction types. It is suitable for creative review, compliance management, and structured-output model training.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| constraints | array | The individual compliance rules extracted from the source instruction. |
| source_instruction | string | The original instruction text containing compliance requirements for out-of-home advertising. |
