# Ground Coffee Processing Quality and Mass-Balance Calculation Verification Dataset

Structured in JSON, the dataset records ground coffee processing batch inputs, post-grinding outputs, and any recorded screening or loss data, alongside yield, loss-rate, and mass-balance calculations for verification. Reference results and verification evidence support checks for calculation errors, unit handling, and batch material-balance consistency, serving production accounting and outcome-verifier training.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| batch_data | object | Recorded batch measurements, submitted calculations, and comparison tolerances supplied for verification. |
| verification_results | object | Normalized reference values, expected calculations, comparisons, and the overall verification outcome derived from the raw batch data. |
