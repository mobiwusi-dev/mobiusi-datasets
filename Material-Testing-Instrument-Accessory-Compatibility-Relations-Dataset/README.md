# Material Testing Instrument Accessory Compatibility Relations Dataset

This dataset covers equipment compatibility, specimen suitability, and intended-use information drawn from product pages and technical documentation for material testing accessories such as fixtures, compression platens, and extensometers. Its relation annotations connect accessories, testing equipment, specimens, and applications, with supporting source text for traceability. It can support relation extraction fine-tuning, instrument configuration knowledge management, and accessory selection.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| source_content | string | Original webpage text or technical documentation used as the source for relation extraction. |
| compatibility_relations | array | Relations among testing accessories, equipment, specimens, or intended applications, with supporting evidence from the source. |
