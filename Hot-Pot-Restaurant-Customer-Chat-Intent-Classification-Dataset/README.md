# Hot Pot Restaurant Customer Chat Intent Classification Dataset

This dataset contains customer chat messages about hot pot restaurant services, paired with service intent annotations across common stages such as reservations and waitlists, menus and ingredients, ordering, dining assistance, and checkout. Its fields include the original customer message, a broad intent category, and a specific intent label, supporting intent recognition and service request routing for hot pot dining. It is suitable for task-specific fine-tuning, classifier training, and chatbot evaluation.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| intent_label | string | The specific service intent assigned to the customer's message. |
| intent_category | string | The broad service area that best describes the customer's request. |
| customer_message | string | The original text of the customer's chat message. |
