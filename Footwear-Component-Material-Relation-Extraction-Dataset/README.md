# Footwear Component-Material Relation Extraction Dataset

Designed for footwear retail catalogs, this dataset contains product descriptions covering uppers, linings, midsoles, outsoles, and other footwear components. It represents identified components and their associated materials as structured relations, with supporting source evidence for traceability and review. The data supports footwear catalog structuring, product knowledge graph construction, and training or evaluation of models that produce structured outputs.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| catalog_description | string | The original footwear product catalog text used as the source for extraction. |
| component_material_relations | array | Structured pairs linking each identified footwear component to its associated material, with supporting source evidence. |
