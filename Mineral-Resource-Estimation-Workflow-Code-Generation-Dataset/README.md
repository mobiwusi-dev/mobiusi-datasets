# Mineral Resource Estimation Workflow Code Generation Dataset

This dataset provides paired text-and-code examples that translate mineral resource estimation requirements into workflow code. Specifications may cover estimation methods, search parameters, sample data, and geological domain constraints, with workflows involving methods such as inverse distance weighting and kriging. It supports training and evaluation of code generation for mine geology and resource modeling software; the dataset's sample volume and execution environment should be confirmed in the delivery details.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| workflow_code | string | Code generated to implement or configure the resource estimation workflow. |
| estimation_method | string | The estimation method specified, such as inverse distance weighting or kriging. |
| implementation_language | string | The programming or scripting language used for the generated workflow code. |
| estimation_specification | string | Natural-language requirements describing the estimation method, search parameters, sample data, and geological domain constraints. |
