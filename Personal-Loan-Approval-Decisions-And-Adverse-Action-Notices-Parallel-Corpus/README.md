# Personal Loan Approval Decisions and Adverse Action Notices Parallel Corpus

This corpus contains bilingual parallel texts covering personal loan approval outcomes, changes to loan terms, and denial or other adverse action notices, paired with translation instructions and reference translations. Focused on decision reasons, loan terms, and related explanations, it supports training and evaluation of models for accurate, complete, and appropriately cautious financial text translation.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| source_text | string | The original-language text of a personal loan decision, loan term change, denial, or adverse action notice. |
| reference_translation | string | A reference translation that preserves the decision reasons, loan terms, and relevant explanations in the source text. |
| translation_instruction | string | Instructions for translating the source text, including requirements for preserving meaning, tone, and completeness. |
