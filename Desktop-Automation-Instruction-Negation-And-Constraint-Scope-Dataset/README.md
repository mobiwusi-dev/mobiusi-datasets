# Desktop Automation Instruction Negation and Constraint Scope Dataset

This collection contains text instructions for desktop automation, covering negation, exceptions, restrictions, and scope limitations, with annotations linking each constraint expression to the instruction content it governs. Focused exclusively on instruction text, it contains no interface imagery and supports instruction tuning to improve models' understanding of constraints and their ability to follow operational requirements. It is suited to instruction understanding training and evaluation for desktop process automation platforms.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| instruction_text | string | The original desktop automation instruction containing one or more constraints. |
| constraint_annotations | array | Annotations identifying each constraint expression and the instruction content it governs. |
