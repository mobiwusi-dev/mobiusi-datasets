# Commercial Litigation Pleadings and Legal Documents Named Entity Recognition Dataset

Designed for web-accessible commercial litigation complaints, answers, and related legal documents, this dataset provides source text, document types, and annotations for litigation-related entities. Coverage includes parties, counsel, courts, and businesses, contracts, and commercial products involved in disputes. The documents focus on claims and procedural narratives rather than judicial opinions, supporting task-specific fine-tuning, evaluation, and legal information extraction research.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| entities | array | Litigation-related named entities identified in the source text, with their text positions. |
| document_text | string | Original text of the web-accessible legal document, used as input for entity recognition. |
| document_type | string | Document category identified from its content, such as a complaint, answer, or other legal document. |
