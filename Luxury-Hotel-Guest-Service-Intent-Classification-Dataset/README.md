# Luxury Hotel Guest Service Intent Classification Dataset

This dataset contains chat text between hotel guests and service teams, covering common service interactions such as reservations, check-in, room service, concierge requests, facility inquiries, billing, and check-out. Each record provides the conversation, the extracted guest message, and its service intent label. It supports fine-tuning and evaluation of models that interpret hotel service requests and classify them consistently.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| guest_message | string | The guest message extracted from the conversation for intent classification. |
| intent_category | string | The service intent assigned to the guest message. |
| conversation_text | string | The original chat transcript between the guest and the hotel service team. |
