# 3D Engine Physics and Collision Code Generation Dataset

This dataset pairs natural-language physics requirements for rigid bodies, colliders, constraints, forces, and collision responses with engine scripting code that implements the requested behavior. It covers common physics interaction setups and logic for real-time 3D simulation, with code provided in a JavaScript-compatible form. The paired examples support supervised code fine-tuning, natural-language-to-code training, and evaluation of physics behavior programming.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| request_text | string | The original natural-language request describing rigid bodies, colliders, constraints, forces, or collision responses. |
| generated_code | string | JavaScript-compatible engine scripting code that implements the requested physics behavior. |
