# Macroeconomic and Central Bank News Evidence Extraction Dataset

This dataset contains news text about macroeconomic indicator releases, central bank decisions, and related financial reporting, paired with JSON extraction annotations. The annotations capture indicators or policy matters, values, units, applicable periods, reporting entities, and source-text evidence supporting the extracted fields. It is suited to structured output SFT, financial information extraction, and source-grounded fact verification.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| source_text | string | The original news article or relevant source passage used for extraction. |
| extracted_items | array | Macroeconomic indicators or central bank policy matters identified in the source text, including reported details and supporting evidence. |
