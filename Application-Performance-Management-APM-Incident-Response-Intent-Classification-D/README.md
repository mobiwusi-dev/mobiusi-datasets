# Application Performance Management (APM) Incident Response Intent Classification Dataset

This dataset contains chat-based requests related to performance alerts, service degradation, and troubleshooting, covering incident response scenarios such as reporting a problem, asking about impact scope, and requesting diagnostic help. Each request is labeled with its corresponding intent. It supports fine-tuning and evaluating models that understand and classify user instructions in APM operations contexts, including alert triage, incident response, and automated operations dialogue.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| intent_label | string | The intent category assigned to the user request, such as reporting a problem, asking about impact scope, or requesting diagnostic assistance. |
| request_text | string | The original chat message describing a performance alert, service degradation, troubleshooting issue, or request for assistance. |
