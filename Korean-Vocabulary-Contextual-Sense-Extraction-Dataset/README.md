# Korean Vocabulary Contextual Sense Extraction Dataset

Designed for Korean learning texts, this dataset pairs source passages containing vocabulary instances with structured JSON annotations. The annotations cover lemmas, parts of speech, contextual senses, and supporting evidence spans, enabling vocabulary-level semantic analysis and information extraction. It is suitable for Korean learning tools, semantic understanding research, and structured-output supervised fine-tuning.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| source_text | string | The original Korean learning text containing the vocabulary instances to analyze. |
| vocabulary_instances | array | Vocabulary instances extracted from the source text, including their lemmas, parts of speech, contextual senses, and supporting evidence. |
