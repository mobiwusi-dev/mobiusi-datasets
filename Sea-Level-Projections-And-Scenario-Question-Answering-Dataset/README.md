# Sea-Level Projections and Scenario Question Answering Dataset

This dataset organizes questions, answers, and supporting evidence derived from reports and technical documents on emissions and projection scenarios, time horizons, relative sea-level change, vertical datums, and uncertainty. Its records focus on sea-level projection knowledge and support the training and evaluation of systems that retrieve relevant information and answer questions using supplied sources. It can help assess whether retrieved material supports an answer and whether a model correctly interprets scenario and projection details.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| qa_items | array | Question-and-answer records with scenario details, projection values, uncertainty, and supporting evidence. |
| source_document | object | The report or technical document used to create the question-and-answer records. |
