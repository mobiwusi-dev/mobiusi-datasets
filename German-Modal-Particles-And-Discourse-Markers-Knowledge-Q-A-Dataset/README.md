# German Modal Particles and Discourse Markers Knowledge Q&A Dataset

This web-text dataset brings together explanations and contextual notes on German modal particles such as doch, ja, mal, wohl, and eben, as well as connective discourse markers. Its expert-level question-and-answer examples focus on tone, communicative intent, and positional constraints. The material supports German pragmatics learning, knowledge-based question answering, and domain-specific supervised fine-tuning.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| answer | string | An accurate and complete explanation based on the webpage material, written to be accessible to German learners in Chinese or bilingually. |
| evidence | object | The webpage excerpts supporting the answer and their relationship to the question-and-answer conclusions. |
| examples | array | German example sentences with Chinese translations and pragmatic analyses that illustrate how the target expression is used. |
| question | string | An expert-level question about the pragmatic use of the target German modal particle or discourse marker. |
| question_type | string | The type of pragmatic knowledge primarily examined by the question-and-answer pair. |
| usage_context | object | The conversational setting, speaker intent, listener effect, and register appropriate to the target expression. |
| source_webpage | object | The webpage source and original content used to generate the question-and-answer pair. |
| target_expression | string | The German modal particle or connective discourse marker addressed by the question, such as doch, ja, mal, wohl, or eben. |
| pragmatic_functions | array | The communicative functions served by the target expression in context, such as emphasis, reminding, conjecture, mitigation, confirmation, or connection. |
| position_constraints | array | Restrictions and conditions governing the target expression's placement at the beginning, middle, or end of a sentence or within specific syntactic structures. |
