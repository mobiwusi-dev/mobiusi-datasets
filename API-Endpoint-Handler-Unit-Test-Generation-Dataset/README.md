# API Endpoint Handler Unit Test Generation Dataset

This dataset contains API endpoint handler implementations, supporting context needed to understand and test each handler, and unit test code examples covering common request handling and business behavior. The samples can train models to generate tests from handler code and support endpoint implementation, test authoring, and workflow automation on API development platforms.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| handler_code | string | Source code implementing the API endpoint handler to be tested. |
| unit_test_code | string | Example unit test code covering the handler's request handling and relevant business behavior. |
| related_context | string | Supporting information needed to understand and test the handler, such as route configuration, request and response types, dependencies, or framework conventions. |
