# Mine Safety Monitoring Sensor Integration Code Verification Dataset

This dataset contains source code examples for sensor data ingestion, parsing, and validity checks in mine safety monitoring systems. Each example includes a validation result, defect category, root-cause annotation, and explanation, covering issues such as missing values, out-of-range values, and stale readings. It supports code correctness checks, defect identification, root-cause analysis, and quality evaluation for mining monitoring software.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| root_cause | string | The code logic or implementation reason that caused the verification issue. |
| source_code | string | Source code for sensor data ingestion, parsing, or validity checks to be verified. |
| defect_category | string | The identified code issue category, such as missing-value handling, out-of-range checks, or stale-reading validation. |
| validation_result | string | The verification conclusion regarding code correctness and its sensor data processing behavior. |
| validation_explanation | string | The verification evidence, relevant code behavior, and impact of the issue. |
