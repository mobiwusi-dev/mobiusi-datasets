# AR Social Filter Requirements-to-Code Dataset

This dataset pairs natural-language requirements for AR social filters with corresponding JavaScript implementations. The requirements describe filter appearance, scene elements, and interactive behaviors, reflecting the practical workflow of creating social and entertainment filters. The paired examples support training models to translate creative intent into filter code, as well as evaluating code generation and developing prototypes.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| requirement_text | string | Natural-language requirements describing the filter's appearance, scene elements, and interactive behavior. This is the input for generating the implementation code. |
| implementation_code | string | JavaScript code implementing the AR social filter based on the corresponding requirements. |
