# Traditional Music Performance Practices and Context Q&A Dataset

This dataset provides closed-domain question-answer pairs about specific traditional music practices, covering performance techniques, ensemble roles, occasions of use, and sociocultural contexts. Each record includes source material, a question category, an answer, and supporting evidence, with answers grounded strictly in the supplied specialist text for traceability and review. It is suitable for traditional music question answering, domain-specific supervised fine-tuning, and cultural heritage information retrieval.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| answer | string | A closed-domain answer based solely on the supplied specialist text. |
| question | string | A question about traditional music performance techniques, ensemble roles, occasions of use, or sociocultural contexts. |
| source_text | string | Specialist source material used to answer the question. |
| question_category | string | The knowledge category addressed by the question. |
| supporting_evidence | string | A verifiable relevant excerpt from the specialist text or an explanation of the supporting basis. |
