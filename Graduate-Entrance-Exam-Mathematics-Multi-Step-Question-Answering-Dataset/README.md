# Graduate Entrance Exam Mathematics Multi-Step Question Answering Dataset

This dataset contains graduate entrance exam mathematics questions paired with reference solutions, covering problems that require connecting conditions, relevant theorems, and calculations across multiple steps. Each sample includes the original question, a worked solution, and ordered reasoning steps to support learning the path from problem analysis to a final result. It is suitable for exam preparation, reasoning-focused SFT, and mathematical problem-solving evaluation.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| question_text | string | The original graduate entrance exam mathematics question, including its conditions and requested result. |
| reasoning_steps | array | Ordered steps connecting the problem conditions to mathematical results, calculations, and the solution. |
| reference_solution | string | The worked answer, including relevant theorems, calculations, and the final result. |
