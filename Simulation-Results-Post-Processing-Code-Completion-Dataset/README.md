# Simulation Results Post-Processing Code Completion Dataset

This dataset covers common simulation post-processing workflows, including result loading, derived quantity calculation, data filtering, plotting, and result export. Each training example pairs an incomplete code snippet with its completed version, supporting model development for engineering simulation analysis and visualization. It is suitable for training code assistants, improving simulation result processing workflows, and evaluating code completion capabilities.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| completed_code | string | The complete code snippet produced by continuing the incomplete code. Used as the target output for model training. |
| incomplete_code | string | An unfinished code snippet from a simulation post-processing workflow, such as result loading, derived quantity calculation, data filtering, plotting, or export. Used as input for code completion. |
