# Unity AR Learning Interaction Code Dataset

This dataset pairs functional requirements for AR courses with corresponding Unity C# interaction implementations, covering teaching behaviors such as tap-to-display actions, model manipulation, step-by-step guidance, and learning-state transitions. The paired requirements and code help models learn to translate natural-language interaction instructions from educational settings into implementable AR teaching features. It is suitable for Unity AR education app development, code-generation model fine-tuning, and related capability evaluation.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| unity_apis | array | Unity or AR Foundation APIs identified in the implementation. |
| csharp_code | string | The original Unity C# code implementing the AR interaction described by the requirement. |
| learning_action | string | A concise derived description of the learner-facing action supported by the implementation. |
| requirement_text | string | The original natural-language description of the educational AR interaction to implement. |
| interaction_category | string | The derived primary category of the AR teaching interaction. |
