# GRE Math Concepts and Commonly Misunderstood Boundary Cases Q&A Dataset

This collection focuses on GRE Quantitative Reasoning and presents question-and-answer pairs grounded in source web text. It covers mathematical definitions, conditions for applying rules, boundary cases, common misconceptions, corrective explanations, and illustrative examples or counterexamples. The content supports accurate, well-explained responses to detailed GRE math questions rather than serving primarily as a collection of test questions and answers.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| answer | string | An accurate, direct response that explains the relevant mathematical knowledge. |
| question | string | A study question about a mathematical concept, rule applicability condition, or boundary case. |
| source_text | string | The original web page body text used as the basis for the question and answer. |
| concept_name | string | The name of the mathematical concept, theorem, operation rule, or object addressed in the Q&A. |
| boundary_case | string | A noteworthy threshold value, special value, or rule boundary, together with the correct treatment of that case. |
| topic_category | string | The GRE math topic for the question, such as arithmetic, algebra, geometry, data analysis, or number theory. |
| concept_definition | string | A clear, standard definition of the relevant mathematical concept. |
| common_misconception | string | A frequent misreading, incorrect inference, or confusion about the scope of a concept or rule. |
| corrective_explanation | string | An explanation of the correct approach to a misconception, including why the error occurs or how to avoid it. |
| applicability_conditions | string | The prerequisites, scope, or limitations required for the relevant rule or conclusion to hold. |
| example_or_counterexample | string | An example or counterexample that clarifies a concept, tests applicability conditions, or distinguishes a boundary case. |
