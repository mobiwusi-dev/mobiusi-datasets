# Behavioral Medicine Dialogue Implicit-Intent Hard Cases Dataset

This dataset pairs behavioral medicine dialogue text with intent labels, focusing on implicit, indirect, and multiple intents that require conversational context to identify. Examples include stating a difficulty as an indirect request for help or expressing ambivalence while signaling willingness to change. The context-dependent and easily confused expressions support fine-tuning and evaluation of dialogue intent understanding; consult the product page for sample counts and data specifications.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| dialogue_text | string | Dialogue text provided as the source input for intent annotation. |
| intent_labels | array | One or more intents inferred from the dialogue context, including implicit, indirect, or multiple intents. |
