# IELTS Writing Assessment Criteria Q&A Dataset

This dataset covers questions about IELTS Writing assessment criteria, band descriptors, and the meaning of scoring standards. Each record includes reference material, an answer, the relevant assessment criterion and band description, and supporting evidence excerpts. It supports retrieval of scoring guidance, clear explanations of assessment standards, and evaluation of retrieval-augmented systems for IELTS preparation.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| answer | string | A clear and accurate explanation of the question based on the reference material. |
| question | string | A question about IELTS Writing assessment criteria, band descriptors, or the meaning of scoring standards. |
| source_evidence | string | A key excerpt or relevant passage from the reference material that supports the answer. |
| band_description | string | The band-level description addressed in the answer, or a note indicating that no specific band applies. |
| reference_material | string | The IELTS Writing assessment criteria or exam-preparation guidance used to answer the question. |
| assessment_criterion | string | The IELTS Writing criterion addressed in the answer, such as Task Response, Coherence and Cohesion, Lexical Resource, or Grammatical Range and Accuracy. |
