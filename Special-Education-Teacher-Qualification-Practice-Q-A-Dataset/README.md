# Special Education Teacher Qualification Practice Q&A Dataset

This dataset brings together questions, answers, and explanations from special education teacher training and qualification practice webpages. Topics include disability categories, individualized education programs, classroom support, behavioral intervention, and family-school collaboration. Standardized questions, answers, knowledge-point tags, and explanation summaries support domain fine-tuning, exam-preparation tools, and evaluation of specialized educational question answering.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| quality_flags | object | Flags generated by automated assessment of question-answer record completeness and answer quality. |
| question_type | string | Standardized question format derived from the original question and its options. |
| source_record | object | Original question record extracted from a special education teacher training or qualification practice webpage. |
| standard_answer | string | Training-target answer produced by normalizing, correcting, and fully expressing the original answer. |
| difficulty_level | string | Question difficulty derived from conceptual complexity, reasoning requirements, and practical context. |
| knowledge_points | array | Special education concepts extracted from the question, answer, and explanation. |
| explanation_summary | string | Concise rationale and professional explanation distilled from the original explanation. |
| normalized_question | string | Question text cleaned of webpage formatting and standardized terminology while preserving its original meaning. |
| pedagogical_recommendations | object | Teaching and support recommendations generated from the special education practice topics addressed by the question. |
