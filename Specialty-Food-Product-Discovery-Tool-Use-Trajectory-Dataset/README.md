# Specialty Food Product Discovery Tool-Use Trajectory Dataset

This dataset records how models use product catalog, category, and product-detail tools to find specialty foods based on origin, ingredients, product type, and dietary preferences. Records include user queries, search constraints, ordered tool calls and results, and final responses, capturing the workflow from understanding a request to presenting catalog-supported product information. Use these trajectories to train and evaluate tool selection, parameter construction, and response generation for specialty food retail applications.
