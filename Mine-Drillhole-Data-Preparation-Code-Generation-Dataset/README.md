# Mine Drillhole Data Preparation Code Generation Dataset

This dataset contains text-to-code examples for drillhole data preparation workflows in mine geology and resource modeling software. Examples pair natural-language requests with Python scripts for tasks such as data import, field mapping, format conversion, interval compositing, and basic validation. It supports code SFT, workflow automation, and evaluation of models that generate scripts for mine geology data engineering.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| generated_code | string | A Python script that implements the requested drillhole data preparation workflow. |
| natural_language_request | string | A user request describing drillhole data import, field mapping, format conversion, interval compositing, or basic validation requirements. |
