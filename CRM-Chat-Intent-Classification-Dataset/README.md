# CRM Chat Intent Classification Dataset

This dataset contains CRM-related requests expressed in chat, covering common workflows such as contact and account management, sales opportunity follow-up, activity logging, and report queries. Each user message is labeled with its primary intent. Use it to fine-tune models to understand natural-language instructions and identify CRM actions for intent routing, workflow automation, and conversational CRM assistants.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| user_message | string | The original user message expressing a CRM-related request. |
| primary_intent | string | The main CRM workflow intent expressed in the user message. |
