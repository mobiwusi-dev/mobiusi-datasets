# SAT Score Reporting and University Submission Policy Multi-Hop QA Dataset

This dataset covers SAT exam structure, score reporting, score release and submission rules, superscoring guidance, and score submission or test-optional policies published on university admissions pages. Each question links SAT rules with policies from a specific institution across multiple sources. Original web text, structured facts, linkage analysis, evidence citations, and final answers support the evaluation of retrieval and multi-hop reasoning in SAT preparation and college admissions advising.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| final_answer | string | The user-facing answer generated by combining SAT score reporting mechanisms with the relevant university submission policy. |
| question_text | string | The original question that requires combining SAT score reporting rules with a specific institution's submission policy. |
| sat_score_facts | object | Structured exam components, score ranges, and score reporting rules extracted from the original SAT rules source. |
| linkage_analysis | object | Intermediate analysis connecting SAT score reporting rules with university submission policies to support reasoning. |
| sat_rules_source | string | Original source text covering SAT exam structure, score reporting, score release timing, submission rules, or superscoring guidance. |
| answer_confidence | number | A numerical estimate of confidence in the cross-source reasoning result, ranging from 0 to 1. |
| evidence_citations | array | Key supporting evidence from the SAT rules source and the university policy source. |
| university_policy_facts | object | Structured institution identity, SAT submission requirements, and test-optional policy facts extracted from university admissions pages. |
| university_policy_source | string | Original text from a university admissions page covering SAT submission requirements, test-optional policies, or superscoring policies. |
