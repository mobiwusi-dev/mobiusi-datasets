# Varistor Nonlinear Voltage–Current Characteristic Symbolic Reasoning Dataset

This collection focuses on problems built around a specified empirical varistor voltage–current model and its given parameters, asking models to derive relationships among voltage, current, and the nonlinear exponent. Tasks cover symbolic rearrangement, solving for unknowns, and formula derivation. It supports training and evaluation of algebraic manipulation and mathematical reasoning for nonlinear electrical characteristics, including math SFT, varistor analysis, and electrical engineering education.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| derivation | string | A clear sequence of algebraic transformations and reasoning steps used to obtain the symbolic expression or solve for the unknown. |
| final_answer | string | The requested solved value, formula, or relationship, stated clearly with relevant units or assumptions when applicable. |
| verification | string | A concise check that the result satisfies the given model and conditions, or a note explaining any applicable domain restrictions. |
| input_problem | string | The original problem statement, including the empirical voltage-current model, given parameters, known quantities, and requested unknown or relationship. |
| symbolic_expression | string | The derived symbolic expression relating voltage, current, and the nonlinear exponent, or expressing the requested unknown. |
