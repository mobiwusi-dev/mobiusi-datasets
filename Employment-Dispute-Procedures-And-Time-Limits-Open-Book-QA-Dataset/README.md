# Employment Dispute Procedures and Time Limits Open-Book QA Dataset

This dataset covers employment dispute procedures, admissibility and jurisdiction rules, and related time limits. Each sample includes a question, supporting materials, an answer, the applicable procedure, relevant admissibility or jurisdiction details, time-limit information, and traceable citations. It supports retrieval of procedural information, open-book question answering, and evaluation of retrieval-augmented generation systems.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| answer | string | A direct response to the question grounded in the supplied source materials. |
| question | string | A question about employment dispute procedures, admissibility, jurisdiction, or applicable time limits. |
| source_citations | string | Traceable references to supporting materials, such as document titles, provisions, sections, or quoted passages. |
| source_materials | string | Procedural rules and dispute-handling materials supplied as the basis for answering, including relevant excerpts and source identifiers. |
| applicable_procedure | string | The relevant dispute-resolution process or procedural steps identified for the question. |
| applicable_time_limits | string | Relevant limitation periods, filing deadlines, or other procedural time limits, including triggering events and qualifications where specified. |
| admissibility_or_jurisdiction | string | The relevant acceptance, admissibility, or jurisdiction rules and how they apply to the question. |
