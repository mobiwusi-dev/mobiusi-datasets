# Open Educational Resources Evidence Passage Retrieval Dataset

This dataset contains learning questions or knowledge queries about educational resource pages, including open textbooks and course materials, along with the original page content, candidate evidence passages, and relevance annotations. It supports training and evaluation of models that locate passages in web text that can substantiate answers, making it useful for evidence retrieval and ranking research in educational question answering.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| query | string | A learning question or knowledge query used to retrieve evidence from open educational resources. |
| source_document | string | The original HTML content of an educational resource page, such as an open textbook or course page. |
| evidence_passages | array | Candidate passages extracted from the source page, with relevance annotations for the learning question. |
