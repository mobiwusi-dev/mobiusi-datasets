# Social Media Advertising Briefs and Structured Creative Generation Dataset

This dataset pairs social media advertising briefs with corresponding structured creative objects, covering elements such as ad copy, headlines, calls to action, and platform information in specified fields and nested formats. Samples are presented as prompt-response examples for training models to generate well-structured creative data from advertising requirements. The data supports structured-output supervised fine-tuning and workflows for creating social media advertising content.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| brief | object | The original advertising brief information used as the basis for creative generation. |
| creative | object | A structured advertising creative generated from the brief for use in social media campaigns. |
