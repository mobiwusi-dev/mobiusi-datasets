# Heavy Metal Contamination Remediation Intervention Counterfactual QA Dataset

This question-and-answer dataset covers heavy metal contamination scenarios in soil or water, with a stated contamination baseline and hypothetical changes to remediation measures, timing, or coverage. Questions may compare options such as removing contaminated soil, applying stabilization treatment, or taking no action; answers analyze how these conditions could affect contaminant risk or migration while stating the limits of the evidence. It is designed to train and evaluate conditional reasoning about heavy metal remediation strategies.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| answer | string | A direct response to the question that explains how contaminant risks or migration could change under different intervention conditions. |
| question | string | The original question-and-answer input, including the contamination baseline and hypothetical conditions involving changes to remediation measures, timing, or coverage. |
| reasoning | string | Compares intervention options and their possible effects based on the scenario, explaining how the conclusion follows from the contamination baseline and changes to the proposed measures. |
| uncertainty_note | string | Identifies information missing or insufficient in the scenario and avoids asserting outcomes that are not supported by the stated conditions. |
