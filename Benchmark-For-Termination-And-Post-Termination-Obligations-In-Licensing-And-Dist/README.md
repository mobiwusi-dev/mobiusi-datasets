# Benchmark for Termination and Post-Termination Obligations in Licensing and Distribution Agreements

This benchmark evaluates how well models interpret end-of-term provisions in licensing and distribution agreements, including termination triggers, mechanisms, eligible parties, notice and cure requirements, and effective timing. It also covers post-termination inventory handling, changes to licensed rights, financial settlements, surviving obligations, restrictions, and relevant exceptions, with supporting contract language for analysis. It is designed for legal document evaluation, contract review workflow testing, and legal AI development.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| payment_settlement | string | Outstanding fees, accrued payment obligations, refunds, credits, or other financial settlement requirements following termination. |
| supporting_evidence | string | Relevant contract language supporting the extracted termination and post-termination analysis. |
| source_contract_text | string | The original contract text or relevant excerpt provided for analysis. |
| inventory_disposition | string | How remaining inventory must or may be handled after termination, including sell-off rights, return, destruction, or purchase obligations. |
| surviving_obligations | string | Obligations that expressly or implicitly continue after termination, such as confidentiality, indemnification, or recordkeeping. |
| termination_mechanism | string | The applicable termination route, such as termination for cause, termination for convenience, or automatic termination. |
| termination_right_holder | string | The party or parties entitled to exercise the relevant termination right. |
| exceptions_and_conditions | string | Exceptions, qualifications, dependencies, or conditions that affect the interpretation or application of the termination and post-termination provisions. |
| termination_trigger_summary | string | A concise summary of the events or conditions that permit or require termination under the contract. |
| notice_and_cure_requirements | string | The required notice, delivery method, cure opportunity, and any stated time limits or conditions. |
| termination_effective_timing | string | When termination takes effect, including any notice period, cure period, or event-based timing stated in the contract. |
| post_termination_restrictions | string | Restrictions applicable after termination, including use of intellectual property, branding, customer relationships, or confidential information. |
| license_rights_after_termination | string | The effect of termination on licensed rights, including cessation, transition, or any limited continuing authorization. |
