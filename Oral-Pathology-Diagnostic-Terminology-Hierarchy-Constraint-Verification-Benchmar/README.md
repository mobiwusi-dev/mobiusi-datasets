# Oral Pathology Diagnostic Terminology Hierarchy Constraint Verification Benchmark

This structured JSON benchmark covers oral pathology diagnostic terms, terminology hierarchies, controlled-term rules, and reference validation results. Its test cases include hierarchy mismatches, conflicts between mutually exclusive attributes, and invalid term combinations, allowing evaluation of whether a model applies domain constraints rather than merely matching terms. It supports domain-specific model evaluation, terminology quality control, and the development of structured validation workflows.
